# claude-games

Browser games built with Claude.

| Game | Folder | Play |
|---|---|---|
| Wildgrove Tamers | [`wildgrove-tamers/`](wildgrove-tamers/) | Open `wildgrove-tamers/index.html` in a browser |

## Hosting with GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)`.
The game will then be at `https://<user>.github.io/claude-games/wildgrove-tamers/`.
